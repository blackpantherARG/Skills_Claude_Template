# Skills_Claude_Template 🗺️
### 🥷 SKILLS - 
#### ¿Qué es una skill?
Un archivo Markdown (SKILL.md) que describe cómo operar sobre un input dado dentro de un contexto determinado: mismo input, mismo procedimiento, mismo formato de salida. Es la unidad que permite replicar un criterio de trabajo en lugar de reexplicarlo en cada conversación.

#### Qué incluye
- Formulario guiado en tres niveles: metadata (siempre en contexto), cuerpo (se carga al dispararse) y recursos (solo bajo demanda).
- Linter en vivo: valida el name, exige que la description diga qué hace y cuándo dispararse, marca la redacción tibia y controla el presupuesto de líneas.
- Medidor de fuerza de disparo, el factor que más incide en que la skill se activa cuando corresponde.
- Salida lista para copiar o descargar como ~/skills/<nombre>/SKILL.md. Sin dependencias ni build: se abre el HTML en el navegador, sea cual sea.
