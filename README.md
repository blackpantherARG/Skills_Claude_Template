# *Skills_Claude_Template* 🗺️
### 🥷 Objetivo:
-  Se elabora este template con la necesidad de poder tener una base estandar para lograr generar skills para Claude, permitiendonos de esta manera, tener un procesamientos de nuestros datos eficientes alineado a la necesidad que se tiene en el momento.
- Debemos tener presente que una SKILL es un archivo en formato MD (markdown) que nos da la posibilidad de poder replicar acciones de base en un contexto determinado, es decir, operar de la misma forma un input dado.
